# Level build: NEON REEF (level 17)

Bonus Testing Grounds stage (`bonus: true`). Horizontal reef traverse,
tier 3. Theme: sunken neon reef fused with flooded data ruins — deep
indigo water, teal + magenta bioluminescence, drowned server pylons.
Entry: `?level=17` (Supernova playtest: `?level=17&diff=hard&timescale=1&playtestContinues=unlimited`).

## Sources

- Art: `art-candidates/neon-reef/` (procedural, seeded painter
  `bake-reef-art.mjs` + `brief.md` + `manifest.json` + `bake-report.json`).
  No external references; palette echoes shipped flat-2D junk and orbs.
- Runtime art keys: background `neonReef`, scenery `reefScenery`, wall
  `reefWall` (+ `reefArch` caps, `reefPylon` alternates, `reefBloom` decor),
  boss `neonChoir`, enemies `enemyReefSkimmer` / `enemyReefAngler`,
  powerups `powerupTorrent` / `powerupPhase`. All 11 files ship in the
  production build via `src/assets.js`.

## Structure

reefTeach 14s → pylonWeave 24s → quietLagoon 10s recovery → tideSurge 22s
+ finalBoss (70s of waves). Terrain: offset reef gates with staggered
`along` sides, arch caps from phase 1, skimmer escorts ahead of gates,
gate-aligned pickups (torrent + phase included), recovery lagoon with
repair/shield only. Music: gauntlet/finalBoss (shipped keys).

New combat (all showcased here, all novelty-gated):

- `reefSkimmer` — fast sine weaver (2 HP), aimed shots with a steep
  marksman profile; `reefWake` contrail animation.
- `reefAngler` — slow 5-HP hoverer firing tide-seeker orbs: slow shots
  that bend toward the nearest live pilot for 2.4s, then fly straight.
  `reefLure` breathing bulb + jaw charge glow.
- Waves `reefSurge` (skimmer V + angler anchor) and `tideWeave`
  (skimmer wall with a held safe lane + angler up the gap).
- Boss NEON CHOIR (`docs/boss-builds/neon-choir.md`): `tideResonance`
  lanes plus delayed seeker motes; aimed volleys join at phase 3.
- Player weapon TORRENT: third top-tier gun (Spread/Laser/Torrent).
  Three heavy lances in a tight fast line — single-lane boss damage
  instead of Spread's fan. Same fire path, per-pilot cooldown, no
  recharge gate; `torrent` pickups grant + select it like Laser.
- Powerup PHASE CLOAK: 5s timed invulnerability with a ghost pulse and
  HUD status; per-pilot in co-op.

Curve (Hotshot): 44/48/39/48/44, peak 48 — breather + arc hold, well
under caps; Ashen Graveyard stays hottest. Supernova peak 76.
